**IAM: Users & Groups**

- IAM = Identity and Access Management, **Global** service;
- **Root account** cretaed by default, should NOT be used or shared;
- **Users** are people within organization, and can be grouped;

More info:

- Groups only contain users, not other groups;
- Users don't have to belong to a group, and user can belong to multiple groups;

**Hierarchy of users**

- Root user
  - IAM user 1
  - IAM user 2
    ...
  - IAM user n

! The root user should NOT be used for day-to-day activities

---

**Root user privileges**

- Actions that can be performed only by the root user:
  - _Change account settings_;
  - View certain tax invoices;
  - _Close your AWS account_;
  - Restore IAM user permissions;
  - _Change or cancel your AWS Support plan_;
  - _Register as a seller in the Reserved Instance Marketplace_;
  - Configure an Amazon S3 bucket to enable MFA;
  - Edit or delete an Amazon S3 bucket policy that includes an invalid VPC ID or VPC endpoint ID;
  - Sign up for GovCloud;
