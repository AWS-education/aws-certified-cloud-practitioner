**Redshift**

- Redshift is based on PostgreSQL, but it's not used for OLTP;
- **It's OLAP - only analytical processing**;
- 10x better performance that other data warehouses, scale to PBs of data;
- **Columnar** storage of data (instead of row based);
- Massively Parallel Query Execution (MPP), highly available;
- BI tools such as AWS Quicksight or Tableu integrate with it;

---

**Redshift Serverless**

- Automatically provisions and scales data warehouse underlying capacity;
- Run analytics workloads without managing data warehouse infrastructure;
- Pay only for what you use (save costs);
- Use cases: Reporting, dashboarding applications, real-time analytics;
